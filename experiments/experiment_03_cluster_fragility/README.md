# Experiment 3: Global Stability versus Cluster-Level Fragility

## Objective
Demonstrate that high global partition stability ($ARI \approx 0.85$) masks localized collapse of rare minority clusters ($N=12$), whereas PCCS cluster fingerprints ($F_k$) and the Perturbation Sensitivity Index ($PSI_k$) unmask localized vulnerability and assign descriptive categories (*Perturbation-Fragile* vs *Conditionally Invariant*).

```bash
python experiments/experiment_03_cluster_fragility/run.py
```
