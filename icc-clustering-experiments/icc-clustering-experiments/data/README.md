# Data

This repository does not depend on external downloads.

| Source | Where | Description |
|---|---|---|
| PCCS-style synthetic data | generated by `common/datasets.make_pccs` or `scripts/generate_synthetic_data.py` | N rows, 100 features (15 informative, 15 redundant, 70 pure noise), 4 clusters with mild imbalance, nonlinear and partly overlapping structure, hidden `true_cluster` |
| Gaussian mixtures | `common/datasets.make_scalable` | variable N and d for scaling studies |
| Real data | scikit-learn bundled datasets (iris, wine, breast cancer, digits) | written to `experiments/exp3_real_world_benchmarks/data/` |

Experiment-specific input files are stored next to their results in `experiments/<suite>/data/`.
This top-level folder holds the data documentation and is the default location for datasets you generate yourself.

## Synthetic data profiles

| Profile | Separation scale | Measurement noise (fraction of feature sd) | Rows with missing values | Outlier rows | Borderline / mislabel-like rows | Extra |
|---|---|---|---|---|---|---|
| clean | 1.0 | 0.05-0.15 | 0% | 0% | 0% / 0% | none |
| noisy | 1.0 | 0.30-0.70 | 3% (MCAR, 3-12 cells) | 2% | 2% / 0.5% | none |
| severe | 0.8 | 0.60-1.20 (30% heavy-tailed) | 8% (MCAR, 5-20 cells) | 5% | 4% / 1% | 30% of signal features have 15% of values shuffled |

Columns: `sample_id`, `true_cluster` (hidden ground truth, evaluation only), `observed_cluster` (blank), `noise_flag`
(0 regular, 1 borderline, 2 mislabel-like), `outlier_flag`, `missing_value_count`, `feature_001` ... `feature_100`.
Feature roles are shuffled across columns; ground-truth roles are listed in `docs/data.md`.

## Generate a file
```bash
python scripts/generate_synthetic_data.py --profile noisy --n 3000 --seed 42 --out data/synthetic_noisy.csv
```
